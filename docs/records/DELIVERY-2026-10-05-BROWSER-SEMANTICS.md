The helper disables the accessibility domain after an enabled inspection and always detaches
its session, including enable/read/disable refusals. Separate before/after site counters require
no added provider read/mutation. It does not focus, click, edit or submit an element. These are
selected browser-computed semantics; physical screen-reader behavior, all possible widgets,
shadow/frame reference relationships and full WCAG conformance remain separate acceptance.

W3C describes programmatically available component names, roles, states and values. This guard
addresses selected names/landmarks alongside existing state/focus tests; it does not certify
that whole criterion. See [Name, Role, Value](https://www.w3.org/WAI/WCAG22/Understanding/name-role-value.html).
Chromium documents that enabling its accessibility domain can affect performance until disabled;
the helper explicitly restores that domain before detaching. See [the primary protocol definition](https://chromedevtools.github.io/devtools-protocol/tot/Accessibility/)
and [Playwright CDPSession](https://playwright.dev/docs/api/class-cdpsession).
