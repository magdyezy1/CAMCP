## Retention and output

New explicit v4 definitions store their current form beside an account-identical v3 projection. Existing v3 records
are not rewritten by a run. A new scope, multi-level selection or undeclared setting that v3 cannot represent has
an unsupported legacy level: an old binary can read/list it but refuses execution before provider egress. This
fails closed rather than widening the report; it is not a claim that new v4-only configurations execute on v3.
The projection also refuses an explicitly incomplete campaign declaration and a missing required TikTok/Snapchat
campaign declaration. V3 detail settings that already represent an incomplete window remain representable.

A durable transaction claims the objective-fallback notice once on the first finished linked snapshot. Concurrent
queued runs do not duplicate it. It remains in retained History; a failed run does not consume a completed-delivery
claim. Schedule/edit/retry coverage and automatic activation remain unfinished at this checkpoint.

V4 stores lineage once per account source. Default `get` returns selected and custom metrics, structured parents,
objective and result, and source references. Result definitions reside in the source capsule. Row coverage is
included when partial; summaries retain full coverage counts. Source/level/period quality is retained in the source
capsule, with row-specific omissions/rounding kept on the row. `include.native:true` returns the full normalized
row, native data and recommendation evidence; `include.lineage:true` returns lineage once in the source capsule.
Neither projection recollects data or changes a retained snapshot. Old snapshots retain their original response.

Cross-level evidence compares visible spend, impressions and clicks for the same window and currency. It reports
exact agreement, gap and percentage, partial coverage or unavailable inputs. It never sums reach or different
primary-result meanings. Zero divided by zero stays unknown. A numerical agreement does not establish measurement
setup or independently prove the owner's completeness declaration.
