# التقارير والتصدير

<a id="أنشئ-تقريرًا"></a>

1. في **منشئ التقارير**، اختر الحسابات والمستوى والتواريخ والمقاييس، ثم **جمع التقرير**.
2. اقرأ الإجماليات ومصادرها. **التوصيات** استشارية، والعمل بأيٍّ منها مراجعة جديدة.
3. يحفظ **احفظ التقرير** التعريف لتجمعه مرة أخرى أو تجدوله.

## شارك وسلّم

<a id="شارك-وصدّر"></a><a id="التقارير-المحفوظة-والقوالب-والجداول"></a>

- يمنحك **نزّل CSV** كل الصفوف، ويكتب **التصدير الآن إلى Google Sheets** علامة تبويب.
- يسلّم الجدول الزمني تقريرًا محفوظًا إلى Google Sheets: اختر **سلّم التقارير المكتملة فقط** أو
  **اسمح بتقارير جزئية موضحة بوضوح**.
- تُنشئ **التقارير** حزم تقارير العملاء، وتعرض **الجداول** عمليات التسليم التالية، وتحتفظ **الأدلة والتحليل**
  بالأدلة وراء كل رقم.

<a id="من-يمكنه-التنزيل"></a>

*تسليم غير مؤكَّد إلى Google Sheets*: بعد انتظار قصير، أعد إرساله أو حرّر علامة التبويب. ولا يُكتب تقرير أقدم فوق
تقرير أحدث أبدًا. ولا ينزّل المشاهدون الملفات إلا إذا سمح المالك بذلك في
**إعدادات مساحة العمل ← تنزيل ملفات التقارير**.
