# دليل المالك في AMCP

AMCP مساحة عملك الإعلانية الخاصة: تربط فيها الحسابات الإعلانية لعملائك، وتجهّز الحملات، وتُعدّ تقارير النتائج،
وتحتفظ بسجلّ لكل تغيير، على الموقع أو عبر مساعد ذكاء اصطناعي. ويجد الأعضاء هذا الدليل أيضًا ضمن **المساعدة**.

## كيف يُبقيك AMCP صاحب القرار

<a id="مصطلحات-هذا-الدليل"></a>

- **لا يتغير شيء دون مراجعة.** يقرأ AMCP الحساب، ويعرض بدقة ما سيتغير، ثم ينتظر الاعتماد.
- **تبدأ الحملات الجديدة موقوفة مؤقتًا.** وتشغيل الحملة خطوة مستقلة تخضع للمراجعة.
- **حدودك هي المرجع.** تُفحص سقوف الإنفاق قبل كل تغيير.
- **يُفحص كل تغيير بعد تنفيذه.** تُذكر النتيجة غير الواضحة صراحةً، ولا يُرسل التغيير مرتين أبدًا.
- **زرّ واحد يوقف كل شيء:** **إعدادات مساحة العمل ← إيقاف كل التغييرات**.
- **الأرقام تبقى صادقة.** التقرير الذي تنقصه بيانات يُوسم بأنه جزئي، ولا تُملأ الفجوة بتخمين أو بصفر.
