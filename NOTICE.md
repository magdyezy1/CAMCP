# Attribution and boundaries

AMCP is an independent application. Tool names, descriptions and development fixtures use AMCP naming. Advertising platform names belong to their respective owners; no endorsement is implied. Public vendor discovery documents retain their source URLs and embedded notices. This repository does not include private account exports, provider credentials, or the original project brief.

Baseline catalog metadata was observed during development and subsequently normalized for AMCP. `.mirror/REPORTS/evidence-hashes.json` lists a SHA-256 for each file of that capture. The capture files this repository ships under `.mirror/RAW` are verified against it (`node tools/evidence-hashes.mjs --check`). The others are declared withheld in `.mirror/RAW/WITHHELD.json` under the label `historical_capture_not_shipped`; their digests cannot be checked from this repository. The normalized catalog (`.mirror/CATALOG`, `.mirror/TOOLS.json`) is re-derived from the shipped capture by `npm run capture:check`, except the operation schemas of delegated gateways, which only withheld files hold. These digests do not attest to unmodified external transcripts. Locally authored adapters and schema mappings do not establish complete behavioral equivalence with another service. The generated implementation report explicitly records incomplete workflows and qualification gaps.
