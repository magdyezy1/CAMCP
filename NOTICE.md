# Attribution and boundaries

AMCP is an independent application. Tool names, descriptions and development fixtures use AMCP naming. Advertising platform names belong to their respective owners; no endorsement is implied. Public vendor discovery documents retain their source URLs and embedded notices. This repository does not include private account exports, provider credentials, or the original project brief.

Baseline catalog metadata was observed during development and subsequently normalized for AMCP. Fixture hashes describe the current derived files; they do not attest to unmodified external transcripts. Locally authored adapters and schema mappings do not establish complete behavioral equivalence with another service. The generated implementation report explicitly records incomplete workflows and qualification gaps.
